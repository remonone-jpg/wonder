# 우주 구경하기

다섯 살이 혼자 볼 수 있는 태양계. 행성 표면은 그림이 아니라 실제 탐사선이
찍은 사진이고, 크기·거리·하루·일 년은 전부 NASA의 실측값입니다.

- **읽어줍니다** — 글자를 못 읽는 나이라 이름과 설명을 소리로 냅니다
- **찾아봐요** — 화면에서 끝나지 않게, 밖에 나가 해볼 것을 하나씩 줍니다
- **진짜 크기** — 진짜 비율로 놓으면 행성이 점이 됩니다. 그림책이 거짓말을
  하고 있었다는 걸 보여주는 게 이 토글의 목적입니다

## 실행

```bash
npm install
npm run dev
npm run build     # dist/ 를 아무 정적 호스팅에나 올리면 됩니다
```
