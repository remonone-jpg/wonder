# 우주 구경하기

다섯 살이 혼자 볼 수 있는 태양계에서 시작해, 별·은하·블랙홀과 우주의 역사까지
이어지는 한국어 우주 탐험 사이트입니다. 행성 표면은 그림이 아니라 실제 탐사선이
찍은 사진이고, 크기·거리·하루·일 년은 공식 자료를 바탕으로 계산합니다.

- **쉽게 · 자세히** — 같은 주제를 어린이용 설명과 깊이 읽는 설명으로 나눕니다
- **찾아봐요** — 화면에서 끝나지 않게, 밖에 나가 해볼 것을 하나씩 줍니다
- **진짜 크기** — 진짜 비율로 놓으면 행성이 점이 됩니다. 그림책이 거짓말을
  하고 있었다는 걸 보여주는 게 이 토글의 목적입니다

## 메뉴

- **3D 탐험** — 태양계, 별의 일생, 우주의 시작, 우리 은하·안드로메다·대마젤란운·M87
- **우주 전체 목차** — 23개 주제와 세 가지 읽기 경로
- **비교 실험실** — 천체의 크기, 태양빛이 오는 시간, 자전과 태양일 비교
- **우주 사전** — 22개 낱말과 관련 주제로 이어 읽기

새로운 3D 무대는 교육용 파티클 모형입니다. 점 하나가 별 하나를 뜻하거나 실제
거리·밝기·개수를 그대로 재현하지 않는 경우에는 화면에서 그 범위를 밝혀 둡니다.

## 실행

```bash
npm install
npm run dev
npm run build     # dist/ 를 아무 정적 호스팅에나 올리면 됩니다
```
